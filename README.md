## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**Accelerating SISTA with Proximal Newton Methods**](https://github.com/Inesvvv/Accelerating_SISTA_with_Proximal_Newton_Methods) | Research project on sparse inverse optimal transport. Implemented SISTA from scratch and accelerated it with proximal and damped proximal Newton steps: **~200× fewer iterations** than proximal gradient, with damping keeping it stable up to 500 parameters. Applied to marriage-market data (Choo–Siow, Dupuy–Galichon). | Python, NumPy, SciPy |
